## Описание:
Реализовано диалоговое общение на основе TCP-сокетов (сценарий "сервер – деканат". Клиент передает серверу фамилию студента и четыре оценки по экзаменам сессии. Сервер на основании этих данных выдает результат, есть ли у студента задолжности, если нет, то возможно ли получение стипендии и ее размер.

## Build:
```bash
cd TCP_Dialogue
cmake -B build
cmake --build build
