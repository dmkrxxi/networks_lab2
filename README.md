## Задание 2. Сокеты TCP и UDP
1. Реализовать предложенные лектором модельные сетевые приложения
*  диалоговое общение на основе TCP-сокетов;
*  эхо-сервер на основе UDP-сокетов.
2. Объяснить использование необходимых функций интерфейса WinSocket
3. Предусмотреть:
*  использование в приложениях произвольного количества клиентов (1 или более),
*  распределенный характер приложения, т.е. выполнение клиентов и сервера на различных компьютерах сети, указать необходимые изменения в кодах приложений.
4. Изменить код приложений таким образом, чтобы возможно было передавать от клиента к серверу и обратно данные произвольных типов (структуру). Можно реализовать сценарий, используемый в задании 1 при создании клиент-серверных приложений на основе бинарных файлов.
